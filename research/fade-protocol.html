Failed-break fade

Registered before the run. Executed once on Aug 28 – Oct 9. Verdict: REJECT (−$62.10, 19 trades). Not wired to the live book. Open the result.

Still no edge to deploy Relative-volume selection is rejected. IOVA’s first-half profit is fragile (one day → $0.32, two days → −$17.63). The audited live book is −$34.33. Both IOVA sides stay off. This page only states the next hypothesis so it cannot be rewritten after seeing its P&L.

Hypothesis

When the first valid opening-range break of the day fails to hold, the reversal back into the range is tradable after the frozen costs. A failed break is not assumed to be a profitable fade.

Universe, known by 10:00

Same common stocks as the last pilot (no sector ETFs). Prior close ≥ $5. Prior-day dollar volume ≥ $20M. At least 3 opening bars. Missing data skips that name. No relative-volume rank. That rule was tested and rejected.

Break, then failure

  1. Candidate. After 10:00, the first eligible name that prints a valid opening-range break in clock order is the only candidate that day. Same break rule as the live book: close beyond the actual 9:30–10:00 high or low, and the name leads or lags SPY from that name’s range open. If two names break on the same bar, take the one with the larger range as a percent of price. If none break by 13:00, no trade.
  2. Do not buy the break. Record a theoretical next-open fill only so we can measure the break’s MFE.
  3. Failure (all must hold, and all are known on the signal close):
    • A later bar closes back inside the range (up-break: close < range high; down-break: close > range low).
    • That close is at or before 14:00 New York.
    • From the theoretical breakout fill, MFE never reached +1R before this close.
    If the breakout would have hit its opposite-range stop first, that is a different event and not a fade signal.
  4. Signal time is the close of the first bar that satisfies failure. No waiting to see whether the fade would have worked.

What we will measure

Prediction: fraction of fades that reach the midpoint before the stop (continuation of the fade). Economics: net per session (zeros in), net per trade, drawdown, MFE/MAE, trade count. Sensitivity: net after dropping the one and two best days. Compare to no trade on the same dates. Do not pass on continuation alone.

Sample

  • Jul 17 – Aug 27: spent. We already saw that many breaks did not continue. Using it to judge this fade would be fitting.
  • Aug 28 – Oct 9: still sealed. If this protocol is accepted, the first authorized run is one shot on that window only.
  • A pass there does not go live. It only justifies buying a longer unused tape for a second test.
  • Too few if fewer than 8 fade trades. Then stop and wait for more history. Do not widen the definition to create trades.

Reject / do not promote

Reject if net ≤ 0, if net is worse than no trade, if fewer than 8 trades, or if the two best days account for more than half of a positive net. Do not then change the midpoint, the 14:00 cutoff, or the universe and call the same window a new test.
